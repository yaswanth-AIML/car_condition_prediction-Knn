# 🚗 Car Condition Prediction using KNN

## 📌 Project Overview
This project predicts the condition of a car using a Machine Learning model built with the K-Nearest Neighbors (KNN) algorithm.

The goal of this project is to understand the complete ML workflow including:
- Data preprocessing
- Feature selection
- Model training
- Model evaluation
- Model saving

---

## 🧠 Algorithm Used
- K-Nearest Neighbors (KNN)

Why KNN?
KNN is a distance-based supervised learning algorithm that classifies a data point based on its nearest neighbors.

---

## 📊 Workflow

1. Data Loading
2. Data Cleaning
3. Encoding categorical variables
4. Feature Scaling
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Model Saving using joblib
